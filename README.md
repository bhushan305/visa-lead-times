# Visa Case Times

Daily-updated USCIS processing times by form, category and office: **[visacasetimes.com](https://www.visacasetimes.com)** (also served at usciscasetimes.com).

TanStack Start (React 19, SSR) on Vercel, Supabase, and a daily USCIS scrape that writes a Google Sheet, synced to Supabase by GitHub Actions.

- **Setup, architecture, operations, moving machines:** [SETUP.md](SETUP.md)
- **Quick start:** `npm run setup`, then `npm run dev` (http://localhost:3010)
- **Deploy:** push to `main`
