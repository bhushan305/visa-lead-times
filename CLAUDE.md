# Visa Case Times: notes for Claude

**Read `SETUP.md` first.** It covers domains (GoDaddy), hosting (Vercel `visa-lead-times-v2`), the data pipeline, secrets, runbooks and moving to a new Mac. Keep it up to date when something changes.

Rules that are easy to get wrong here:

- **Ship** = commit and `git push origin main`; Vercel deploys production. Cowork's Linux shell has no GitHub credentials, so the user pushes from their own Terminal.
- **Scraping USCIS only works in the user's real Chrome** (Claude in Chrome on the Mac). Don't try to move it to GitHub Actions, the cloud, or curl. Cloudflare blocks those (403 / "Attention Required").
- **Scraper**: `scripts/uscis-scrape.browser.js` runs in the tab and reports progress on `window.__uscis`. When reading tool output from that tab, avoid returning URLs with query strings (the Chrome tool redacts them).
- **Form labels**: the sync keys forms by `form_label_selected`, so the scraper must build it as `<config form_code> | <title>`. Two labels for one code break the forms upsert.
- **Canonical tags** go in `head().links` via `canonicalUrl()` from `src/lib/site.ts`, never in `meta` and never from an env var.
- `src/routeTree.gen.ts` is generated by the router plugin. Commit it when it changes. `public/sitemap.xml` is generated at build time and gitignored.
- `.env.local` holds secrets. Never print or commit it. Pass it to scripts with `--env-file=.env.local`.
- Running scripts from Cowork's Linux shell: `node_modules` were installed on macOS, so native binaries (esbuild/tsx) don't run there. Install tsx in a scratch dir and run `<scratch>/node_modules/.bin/tsx --env-file=.env.local scripts/...`. Each call has a ~3-minute limit, and the full-history sync takes longer.
- The Google Sheet and Apps Script are owned by bhushan@marketcrunch.ai. Read the sheet through `APPS_SCRIPT_URL?tab=...`.
